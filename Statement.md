❗ Problem Statement

Manual management of the student records is inefficient and takes time and leads to human errors. The education institutions require the system which can efficiently store, fetch, update and manage the information of the students.

This project will provide the solution of developing the Student Management System in Java which will facilitate the process in an organized manner.

🎯 Scope of the Project

Scope of this project includes:

Management of student data (ID, Name and Marks)
Executing CRUD operations (Create, Read, Update, Delete)
Provision of simple and interactive menu-based interface
Illustration of basics of Java including OOP, Collection and Exception handling

👉 This project scope is restricted to the console-based application only without including additional functionality like GUI or cloud storage.

👥 Target Users
Java programming students
Faculty for the purpose of demonstration
Smaller educational institutes having the need for simple record system
Beginners having an interest in practical application of Java

🚀 High-Level Features
Adding new student records
Listing all the students
Searching of student with ID
Updating student details (Marks)
Deleting student records
Grade Calculation
Exception handling for Input Validation
